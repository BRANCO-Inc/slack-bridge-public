# Slack Bridge Public Setup

## Overview

この手順は公開版 Slack Bridge をローカル環境で初期化するための最小セットです。Slack API への接続確認は `docs/smoke-test.md` に分けています。

## Prerequisites

- Python 3.10 以上
- tmux
- Claude Code CLI（既定）
- Codex CLI（`AI_WORKER_PROVIDER=codex` に切り替える場合）
- Slack App の Bot token、App token

## Procedure

1. 依存関係を入れる。

   ```bash
   python3 -m venv venv
   venv/bin/python -m pip install -r requirements.txt
   ```

   Windows の場合:

   ```powershell
   py -3 -m venv venv
   .\venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. 初期ファイルを生成する。

   ```bash
   venv/bin/python scripts/setup.py
   ```

   Windows の場合:

   ```powershell
   .\venv\Scripts\python.exe scripts\setup.py
   ```

3. `.env` を編集する。

   ```bash
   chmod 600 .env
   ```

   Windows native の場合は、通常のファイル権限管理で `.env` を共有しない場所に置きます。

4. `.env` に Slack token、AI worker、tmux path を設定する。

   - `SLACK_BRIDGE_AUTH_TOKEN` は setup が `.env` に生成します。
   - `SLACK_BOT_TOKEN` と `SLACK_APP_TOKEN` は Slack App 管理画面で確認した値を入れます。
   - 既定は `AI_WORKER_PROVIDER=claude` です。Claude Code が `PATH` にあれば `CLAUDE_BIN` は空で構いません。
   - Codex に戻す場合は `AI_WORKER_PROVIDER=codex` にし、必要なら `CODEX_BIN` を設定します。
   - `CLAUDE_BIN`、`CODEX_BIN`、`TMUX_BIN`、`SLACK_BRIDGE_SHELL_BIN` は、設定する場合は実行可能な絶対パスを入れます。
   - WSL の場合は WSL 内の Linux path を使います。
   - Windows の場合は WSL を推奨します。native で使う場合は MSYS2/Git Bash 等で利用できる `tmux.exe` と `bash.exe` などの絶対パスを入れます。

5. doctor を実行する。

   ```bash
   venv/bin/python scripts/doctor.py
   ```

   Windows の場合:

   ```powershell
   .\venv\Scripts\python.exe scripts\doctor.py
   ```

6. Slack App manifest は `config/slack-app-manifest.yaml` を Slack App 管理画面で読み込む。

## Files Generated By Setup

- `IDENTITY.md`
- `config/members.json`
- `config/slack-app-manifest.yaml`
- `.env.example`
- `.env`（0600）

## Notes

- `scripts/doctor.py` は Slack API を呼びません。
- Slack API への接続確認は `docs/smoke-test.md` に沿って手動で行います。
- `.env` は配布物やGit管理へ含めないでください。
- worker 起動は tmux とPOSIX shellを使います。Windowsでは WSL か、MSYS2/Git Bash 等の tmux/shell を指定してください。
